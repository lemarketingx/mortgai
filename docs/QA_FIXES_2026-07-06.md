# תיקוני QA — אבטחה ושלמות לידים (מענה לדוח QA_REPORT_2026-07-06)

**ענף:** `claude/finzo-qa-testing-h93k91` · **היקף:** F-1, F-2, F-3, F-4 בלבד. ללא שינויי UI, ללא שינוי לוגיקת שוק הלידים, ללא deploy.

## מה תוקן

### F-1 — בידוד rate limit לפי endpoint ✅
- `lib/rateLimit.js`: מפתח ה-bucket הוא כעת `${scope}:${ip}` במקום IP בלבד. `recordRateLimitHit` ו-`clearRateLimit` מקבלים את אותם options כדי שהחלון והמונה יהיו עקביים לכל scope.
- כל הקוראים מעבירים scope ייעודי: `lead`, `admin-login`, `advisor-login`, `advisor-register`, `advisor-reset-password`, `advisor-forgot-password`, `unlock`.
- **אומת בריצה:** ‏11 שליחות ל-`/api/lead` → ‏429 על הליד, ומיד אחר כך התחברות אדמין עם סיסמה נכונה → ‏200 (לפני התיקון: 429 ל-15 דקות).

### F-2 — rate limit ל-forgot-password ✅
- `pages/api/advisor/forgot-password.js`: ‏5 בקשות ל-15 דקות לכל IP (כל בקשה נספרת, כי כל בקשה מייצרת אימייל יוצא). מעבר לזה — ‏429 עם Retry-After.
- התשובה הציבורית נשארה גנרית: ‏`{ ok: true }` תמיד — לא נחשף אם האימייל קיים.

### F-3 — קידוד HTML באימיילים ✅
- `lib/email.js`: ‏`escapeHtml` יוצא (exported) כ-helper משותף, וכל ערך בשליטת משתמש שמוזרק ל-HTML עובר דרכו:
  - אימייל "ליד חדש" לאדמין: שם, טלפון, עיר, purchaseStatus (ה-fallback הטקסטואלי), וקישור הליד.
  - אימייל השוק ליועצים: ה-fallback של purchaseStatus (העיר כבר הייתה מקודדת).
  - אימייל תזכורת מסמכים: שם לקוח, שם יועץ, תוויות מסמכים, קישור העלאה.
- בניית ה-HTML של אימייל האדמין חולצה ל-`buildLeadNotificationEmailHtml` המיוצאת — כדי שבדיקות רגרסיה ירוצו על הקוד האמיתי בלי לשלוח אימייל.

### F-4 — אי-חשיפת שגיאות פנימיות ב-`/api/lead` ✅
- תגובת כשל שמירה מחזירה כעת רק `error: "LEAD_SAVE_FAILED"` והודעת משתמש בעברית. השדות `supabaseCode` / `supabaseMessage` / `supabaseDetails` (שכללו שמות משתני סביבה) הוסרו מהתגובה הציבורית.
- הפירוט הפנימי המלא ממשיך להירשם בצד שרת בלבד דרך `logLeadFailure` (ללא שינוי).
